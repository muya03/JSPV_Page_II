# JSPV typography rules

Font stack: `--app-font-sans`: 'Barlow'; `--app-font-display`: 'Barlow Condensed'. Google Fonts import in index.html only — NOT in CSS.

PSOE hierarchy:
- eyebrow → `font-display font-bold text-xs uppercase tracking-[0.18em] text-primary`
- titles → `font-display font-extrabold`
- lead/subtitle → `font-light italic`
- card desc → `font-light`

**Why:** Matches PSOE/JSE brand identity. Do NOT reintroduce Montserrat or Inter — they were replaced in a previous redesign.
